# Vision — cli-notes

## Problem
Developers lose small notes (commands, snippets, reminders) because capturing them
means leaving the terminal.

## Items
- **V-1** Capture and retrieve a note without leaving the terminal.
- **V-2** Primary user: a developer working in a shell all day, on one machine.
- **V-3** Success: adding a note takes under 3 seconds; finding one among 1,000 notes takes under 1 second.
- **V-4** Notes can be exported as plain Markdown files, so they outlive the tool.

## Non-goals
- Real-time collaboration.

## Changelog
- v2: added V-4 (export), requested after early users asked for an exit path.
